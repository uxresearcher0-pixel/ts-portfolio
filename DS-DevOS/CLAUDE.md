# DS DevOS Project Guidance

Follow `AGENTS.md`.

## Interaction contract

For meaningful work:

1. UNDERSTAND
2. ASK only when a missing fact blocks safe implementation
3. CONFIRM the implementation scope
4. EXECUTE
5. VALIDATE
6. STOP and report

Never continue expanding scope automatically.

## Accessibility

- WCAG 2.2 AA
- Semantic HTML first
- Keyboard-only usability
- Visible focus
- Accessible names, roles, states, and error handling
- Test likely effects on NVDA, JAWS, VoiceOver, and TalkBack
- Do not copy a single screen reader's exact announcement as the compliance target

## Git

- Work on a feature branch
- Keep commits focused
- Do not stage unrelated files
- Show `git diff --stat` and validation results before suggesting a commit
